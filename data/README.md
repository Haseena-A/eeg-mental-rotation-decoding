# Data

The recordings are not stored in this repository.

Download the CC0 archive published by Ashwin et al.:

https://doi.org/10.6084/m9.figshare.28120670

Place `STData.zip` in this directory, or run `python scripts/download_data.py` from the repository root. The compressed file is about 1.1 GB. The pipeline reads the EEG and PsychoPy tables from the zip and does not extract them. The uncompressed EEG tables are several gigabytes, and extracting them is unnecessary for the analysis.

Do not add participant spreadsheets that still contain names. The published deposit is described as anonymised. Treat any local file that is not part of that deposit as private.
